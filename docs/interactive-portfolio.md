# Interactive AI Portfolio

The live portfolio is available at https://amarai-jzurfwqv.manus.space. Technology icons respond to hover, keyboard focus, and tap; project cards reveal the documented tech stacks. Detailed evidence and project status are on separate pages.

GitHub README does not execute custom JavaScript or hover CSS. Its GIFs are recordings of the actual interface, and its images/buttons open the real interactive site.

Source is kept in `portfolio/`. The original project repositories and features are unchanged.
